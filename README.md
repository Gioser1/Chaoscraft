- Nueva opción '☄️ Lluvia de TNT que te Persigue (Cae del Cielo)' (TNT_RAIN / TNT_RAIN_TRAP): Disponible tanto en Trampas Mortales como en Eventos Especiales y Secuencias; hace caer TNT encendida desde arriba (1 sola TNT o lluvia continua cada 0.5s) persiguiendo la posición en tiempo real del jugador mientras se mueve, detectando techos si está en cuevas o casas.
